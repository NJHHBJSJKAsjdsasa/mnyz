# 15 · 里程碑、人力与风险（详细设计）

> 对应主文档 §19、§20。本篇给出：每个里程碑的任务拆解与退出标准、依赖与关键路径、人力假设、风险登记册（信号/缓解/触发动作）、节奏与发布检查单。

---

## 1. 里程碑

### M0 基础设施（3–4 天）

| 任务 | 产出 |
|---|---|
| 应用工厂 + 蓝图骨架 | `server/__init__.py`、`server/api/v1/*` |
| 配置与自检 | `config.py`（DSN/Redis/密钥/时钟/参考数据行数） |
| 结构化日志 + 错误中间件 | `infra/logging.py`、problem+json |
| 健康检查 | `/health/live`、`/health/ready` |
| Compose | pg15 + redis + pgbouncer + app + worker + beat |
| Alembic | `alembic.ini`、`env.py`、`0001_core` |
| CI | lint + pytest + 迁移三步 + 前端三件套 |

退出：空库 up→down→up 通过；`ready` 200；CI 绿。

### M0.5 行星缓存（2–3 天）

`PgCacheManager`、`cache` 门面、双写、回填、切读。
退出：1000 key 与 fresh 全等；停 PG 可降级；4 worker 无锁冲突。

### M1 账号（4–5 天）

accounts/sessions/JWT/Argon2id/限流/锁定/审计；参考数据播种。
退出：注册登录刷新登出全通；重放检测生效；限流符合预期。

### M2 账本与状态（5–6 天）

wallets/ledger/对账/幂等表；`/me`、`/state`；影子写。
退出：对账 0；并发采集只成功一次。

### M3 探索域（6–8 天）

采集、扫描、地表、星区、冷却、图鉴、残骸；服务端计算与对拍。
退出：改本地无效；p95 < 150ms；对拍 10k 一致。

### M4 经济域（6–8 天）

行情生成/预热、买卖、合同、改装、生产线。
退出：跨设备一致；过期任务准点；成交价=显示价。

### M5 资产与社交（6–8 天）

船/空间站/舰队/科技/维修/NPC/势力/联盟/排行。
退出：上限在库内生效；排行基于副本。

### M5.5 玩家改造星球（6–8 天）

`planet_*`、`materialize`、账本耦合、审计、配额。
退出：TRUNCATE 缓存后视图不变；双击只生效一次。

### M6 战斗与全量（6–8 天）

战斗状态机、存档导入、压测、灾备演练、灰度 100%。
退出：k6 达标；PITR 演练成功；灰度观察 48h。

### M6.5 共享行星（10–12 天）

`world_planets`、异步攻城、跨区 saga、escrow。
退出：跨区战报全等；结算 10 次只生效一次；无重复发放。

## 2. 依赖与关键路径

```
M0 ─┬─ M0.5
    └─ M1 ── M2 ─┬─ M3 ── M4 ── M5 ── M5.5 ── M6 ── M6.5
                 └─（M2 后任意域可独立接入）
```

关键路径：**M2 → M3 → M4 → M6**。M2 未完成时不要开任何域。

---

## 3. 人力

| 角色 | 人数 | 负载 |
|---|---|---|
| 平台后端 | 1 | M0/M0.5/M2/迁移/观测 |
| 业务后端 | 1–2 | M3/M4/M5/M6 |
| 前端 | 1 | 开关/只读缓存/错误处理 |
| 测试/SRE | 0.5–1 | 契约/压测/演练 |

估算：单人 10–12 周；3 人并行可压到 6–7 周，但迁移与对账不可并行。

## 4. 风险登记册

| # | 风险 | 概率/影响 | 早期信号 | 缓解 | 触发动作 |
|---|---|---|---|---|---|
| R1 | JS/Python 公式漂移 | 高/高 | 对拍差异 > 0 | 对拍进 CI | 停止切流 |
| R2 | 账本/余额不一致 | 中/高 | 对账告警 | 条件更新 + 每小时对账 | 冻结玩家 |
| R3 | 长事务拖垮池 | 中/中 | 池水位/锁等待 | `statement_timeout` | 降级写 |
| R4 | 双写期冲突 | 中/中 | 差异率上升 | 单向权威 + 分域灰度 | 回 local |
| R5 | 分区缺失 | 低/高 | 插入报错 | 预建 3 月 + 告警 | 立即建分区 |
| R6 | beat 停摆 | 中/中 | last_success 超期 | 选主 + 心跳 | 重启/接管 |
| R7 | 导入被滥用 | 中/中 | 资源异常 | 一次性 + 上限 + 审计 | 关闭入口 |
| R8 | 缓存被当数据 | 中/高 | 恢复后资产缺失 | 边界声明 + TRUNCATE 用例 | 停止清理 |
| R9 | 跨区 saga 半成功 | 中/高 | escrow 堆积 | 单事务 + 幂等 + escrow | 人工重放 |
| R10 | 大联盟垄断行星 | 高/中 | 少数持有大量 | 成本加权 + 护盾 + 上限 | 调参 |
| R11 | 灰度期客服压力 | 中/中 | 工单激增 | 强制开关 + 差异看板 | 回滚该域 |
| R12 | 低估工作量 | 高/中 | 连续延期 | 里程碑按可验收产物切 | 缩减范围 |

## 5. 节奏

| 时点 | 动作 |
|---|---|
| 周一 | 对齐本周里程碑与退出标准 |
| 周三 | 中期检查：迁移可回滚、对账平 |
| 周五 | 演示 + 回滚演练一次 + 更新风险表 |

发布窗口：工作日 14:00–17:00（避开晚高峰）；周五不发布。

---

## 6. 发布检查单

- [ ] 账本对账 0（最近 24h）
- [ ] 迁移 up/down 演练通过
- [ ] k6 稳态达标（或本次无性能影响）
- [ ] 回滚脚本可用且演练过
- [ ] 监控/告警就绪，值班知晓
- [ ] 变更单（flag、范围、回滚人）已填
- [ ] 存档兼容性验证（导出/导入各一次）
